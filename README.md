## 4. How to Preview and Deploy Kortex AI

### Local Preview:
Open `index.html` in any web browser, or launch a local server:
```bash
python3 -m http.server 3000
```
Then visit `http://localhost:3000`.

### Deploying to GitHub Pages (Free &amp; Automatic):
1. Go to your GitHub repository: [https://github.com/Hunter-420/kortex_saas_platform](https://github.com/Hunter-420/kortex_saas_platform)
2. Click **Settings** &rarr; **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Method A (GitHub Actions - Recommended):** Set **Source** to **GitHub Actions**. The included `.github/workflows/deploy.yml` workflow will automatically deploy on every push!
   - **Method B (Deploy from a branch):** Set **Source** to **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then click **Save**.
4. In under 60 seconds, your site is live at:
   **`https://hunter-420.github.io/kortex_saas_platform/`**

### Deploying to Vercel (Alternative):
1. Visit [vercel.com](https://vercel.com) and click **Add New** &rarr; **Project**.
2. Select the `Hunter-420/kortex_saas_platform` repository from GitHub.
3. Keep default settings (`Other` framework, root directory `./`) and click **Deploy**.
4. Your custom high-speed Vercel edge production URL will be live instantly!
